🔗 **[Live Application](https://praja-sakti-scoring.vercel.app/)**

---

## 🎯 Business Context & Problem Statement

In real estate compound development, evaluating project readiness, vendor/contractor performance, and multi-parameter feasibility often suffers from subjective assessments and scattered spreadsheet files.

**Key Objectives:**
1. **Standardize Evaluation Criteria:** Provide the Compound Project Development Team with a unified digital interface for scoring project parameters.
2. **Eliminate Manual Calculation Errors:** Automate weight distribution and composite score aggregation in real time.
3. **Centralize Decision Documentation:** Generate structured, consistent evaluation outputs for internal management review.

---

## ⚙️ Key Capabilities

* **Interactive Multi-Criteria Scoring:** Structured evaluation workflow allowing project managers and development teams to score operational parameters systematically.
* **Real-Time Score Aggregation:** Instant client-side calculation of weighted indicators and composite project scores.
* **Clean, Distraction-Free Enterprise UI:** Purpose-built responsive interface optimized for fast internal assessments across desktop and field devices.
